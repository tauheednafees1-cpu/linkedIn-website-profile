# Tauheed Nafees - Personal Portfolio Website

A clean, modern, and fully responsive personal portfolio website built with HTML5, CSS3. This repository contains the source code showcasing my background, skills, educational journey, core competencies, and contact details.

---

## 🌟 Features

- **Modern & Responsive UI**: Clean layout built with flexbox and CSS Grid that adapts seamlessly across all device sizes (Mobile, Tablet, Desktop).
- **Custom Aesthetic**: Soft cream and dark slate palette using CSS variables for simple maintenance.
- **Micro-Interactions & Animations**:
  - Floating ambient background radial glow.
  - Interactive hover states, elevation lifts, and subtle icon rotations.
  - Custom SVG visual illustrations with CSS floating animations.
- **Scroll-Triggered Animations**: Intersection Observer API drives smooth reveal animations with staggered card entries.
- **Zero Heavy Dependencies**: Built purely with vanilla web technologies for lightning-fast performance and fast load times.
